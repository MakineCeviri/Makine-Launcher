Version 0.2.5 — Sturdier installs

• Games whose patch is still being prepared show as "Coming soon" in My Library and All Games; buttons that sent you to other sites are gone.
• Games whose exe lives in a subfolder (such as Phantom Blade Zero) are found and installed; if a folder inside the game was picked, the launcher moves up to the game's folder itself.
• Removing a patch with thousands of files, or cleaning up a failed update, no longer freezes the launcher.
• Ctrl+Q closes the launcher; a backup or patch program still running at exit no longer freezes the window.
• Fixed removing an old-style Red Dead Redemption 2 patch, and the backup error on a full disk.
