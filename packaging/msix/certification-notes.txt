Makine Launcher 0.2.4.0 (0.2.4-beta) - Notes for Certification
--------------------------------------------------------------

WHAT IT IS
A Win32 desktop utility that installs community-made Turkish translation patches into PC games the user already owns (Steam, Epic Games, GOG, Ubisoft Connect). Not a game. No account, login or purchase is needed. The UI is in Turkish only.

WHAT CHANGED SINCE 0.2.3.0
- "Makine": an optional animated companion (a small robot) that reacts to what the launcher does (looks around while games are found, glows while a patch downloads, cheers when it is installed, says when something failed). He stands in a corner of the home page and at the foot of the sidebar elsewhere, drawn in a small transparent window owned by the launcher window: no taskbar button, never takes focus, click-through except his head and hands, hidden while the launcher is minimized. Only if the user picks it in Settings > Görünüm (Appearance) > Makine does he move onto the desktop or above the taskbar clock; the same page turns him off.
- "Topluluk" (Community): the makineceviri.org community wall, readable without an account. Posting, replying and voting need a sign-in with a 6-digit code sent to the user's e-mail, or Discord in the browser. The session token is stored encrypted with Windows DPAPI.
- Redesigned pages, a splash screen and the welcome flow in the launcher's own look.
- Large patches (5,000+ files) no longer freeze the window before installing.

FIRST RUN (about 1 minute)
1. Launch "Makine Launcher" from Start. A 3-step welcome opens: "Başlayalım" (Let's start) -> "Devam" (Continue; game libraries are scanned in the background) -> preferences -> "Makine Launcher'ı aç" (Open Makine Launcher). "Atla, ayarları sonra yaparım" skips it.
2. "Ana Sayfa" (Home) shows featured patches and shelves of covers. On a PC without supported games "Kütüphanem" (My library) is empty. This is expected.

QUICK TEST (no game needed)
1. "Tüm Oyunlar" (All games): the whole catalogue (about 240 games).
2. Click a cover: description (Steam store API), what the install will do, patch notes, credits. If the game is not installed the button reads "Oyun Klasörünü Seç ve Kur" (Pick the game folder and install); nothing is written unless a matching game folder is chosen.
3. "Yenilikler" (What's new) shows this version's notes and "Güncelsin" (You are up to date).
4. "Topluluk" (Community) shows the wall; signing in is optional.
5. "Ayarlar" (Settings) > "Hakkında" (About) shows version 0.2.4.0-beta and links the privacy policy. Settings > Görünüm > Makine: "Nerede dursun" (Where he stays) moves the companion, "Makine'yi göster" (Show Makine) turns him off.

OPTIONAL FULL TEST (needs a catalogue game installed through Steam, Epic, GOG or Ubisoft Connect)
1. The launcher finds the game on its own, or the user adds it with "Oyun ekle" (Add game) or by dropping the game folder on the window.
2. On the game's page "Türkçe Yamayı Kur" (Install Turkish patch) downloads the package from cdn.makineceviri.org, verifies it, backs up every file it will overwrite, then writes the translated files. "Kaldır" (Remove) puts the originals back.
3. For a folder the user cannot write to (e.g. under C:\Program Files) the included helper makine-elevate.exe asks through the standard UAC prompt and copies the files. Only this helper elevates, only for that step; Makine-Launcher.exe always runs asInvoker.

WHY runFullTrust IS NEEDED
The app reads and writes the user's own game folders outside its package, reads Steam/Epic/GOG/Ubisoft install records, lists running processes only to ask the user to close a game before patching it, and starts makine-elevate.exe for protected folders. A few patches ship the translator's own installer; it runs with the user's rights from a temporary copy, without a console window, its output shown on the game page. No drivers or services, no injection into game processes, no changes to anti-cheat software.

NETWORK
- cdn.makineceviri.org: catalogue, images, translation packages, launcher.json (public, read-only)
- makineceviri.org: catalogue updates, anonymous usage counts, the community wall and its optional sign-in
- store.steampowered.com, cdn.akamai.steamstatic.com: game descriptions and images
- ingest.de.sentry.io: crash reports
No inbound connections, no listening ports. Offline the app still opens and shows a "no internet connection" banner.

DATA AND PRIVACY
Anonymous operation results (e.g. install succeeded or failed, app version) and crash/error reports (stack trace, app and Windows version, the failing step); user names are removed from file paths. No personal files are collected. Only a community sign-in sends an e-mail address (to makineceviri.org, for the code); the chosen display name and posts then show on makineceviri.org. Crash reports can be turned off in Settings > General. Privacy policy: https://makineceviri.org/gizlilik-politikasi/ (linked in Settings > About).

OTHER BEHAVIOUR
- "Windows ile başlat" (Start with Windows) and "Kapatınca tepside çalışsın" (Keep running in the tray) are off by default.
- Catalog entries without a package of ours show a disabled "Yakında" (coming soon) state; nothing is downloaded or opened.
- Translations are made by the community and are not official; each game page says so.
