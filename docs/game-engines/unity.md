# Unity Destegi

MakineAI Unity oyun motoru destegi detaylari.

---

## Genel Bakis

**Destek Durumu:** Tam Destek

**Desteklenen Surumler:**
- Unity 2018.x - 2023.x
- Mono build
- IL2CPP build

---

## Nasil Calisir

MakineAI Unity oyunlarinda BepInEx + XUnity.AutoTranslator kullanir:

1. **BepInEx** - Unity mod framework
2. **XUnity.AutoTranslator** - Ceviri hook sistemi

### Calisma Prensibi

```
Oyun Baslat
    |
    v
BepInEx Yukle
    |
    v
XUnity.AutoTranslator Baslat
    |
    v
Metin Hooking
    |
    v
Ceviri Dosyasi Yukle
    |
    v
Turkce Metin Goster
```

---

## Otomatik Algilama

MakineAI Unity oyunlarini su dosyalardan tespit eder:

| Dosya | Aciklama |
|-------|----------|
| `UnityPlayer.dll` | Unity runtime |
| `GameName_Data/` | Data klasoru |
| `Assembly-CSharp.dll` | Mono build |
| `GameAssembly.dll` | IL2CPP build |
| `globalgamemanagers` | Unity asset |

---

## Ceviri Sureci

### 1. BepInEx Kurulumu

```
[Oyun Klasoru]/
├── BepInEx/
│   ├── core/
│   ├── plugins/
│   └── config/
├── doorstop_config.ini
└── winhttp.dll
```

### 2. XUnity Kurulumu

```
[Oyun Klasoru]/
└── BepInEx/
    └── plugins/
        └── XUnity.AutoTranslator/
            ├── XUnity.AutoTranslator.dll
            └── Translation/
                └── tr/
                    └── Text/
                        └── _AutoGeneratedTranslations.txt
```

### 3. Ceviri Dosyasi

Format: Key=Value

```
Hello World=Merhaba Dunya
Start Game=Oyuna Basla
Settings=Ayarlar
```

## Teknik Detaylar

### Mono Build

- IL kodu runtime'da yakalanir
- UGUI Text, TextMeshPro destegi
- Dinamik ceviri mumkun

### IL2CPP Build

- Native hook kullanilir
- Performans daha iyi
- Bazi limitasyonlar olabilir

### Font Destegi

XUnity otomatik font degisimi yapar:
- Unity default fontlar
- TextMeshPro fontlar
- Turkce karakterler icin uygun font

---

## Bilinen Sorunlar

### Anti-Cheat

Bazi Unity oyunlari anti-cheat kullaniyor:
- EasyAntiCheat
- BattlEye

**Cozum:** Sadece singleplayer modda kullanin

### IL2CPP Sinirlari

IL2CPP build'lerde:
- Bazi reflection hook'lar calismayabilir
- Daha az dinamik yetenek

### Asset Bundle Metinleri

Asset bundle icindeki metinler:
- XUnity ile yakalanamayabilir
- Ayri asset patch gerekebilir

## Troubleshooting

### BepInEx Yuklenmiyor

1. `doorstop_config.ini` kontrol et
2. `winhttp.dll` varligini kontrol et
3. Anti-virus istisna ekle

### Ceviri Gorunmuyor

1. `_AutoGeneratedTranslations.txt` kontrol et
2. Encoding UTF-8 olmali
3. XUnity config'de dil "tr" olmali

### Oyun Cokuyor

1. BepInEx surum uyumlulugu kontrol et
2. Diger mod'larla cakisma olabilir
3. Log dosyasini kontrol et: `BepInEx/LogOutput.log`
