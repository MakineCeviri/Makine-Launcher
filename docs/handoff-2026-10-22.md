## Nasıl çalışılır

**Okunacaklar, sırayla:** kök [`CLAUDE.md`](../CLAUDE.md) (mimari, derleme, tuzak tablosu) → [`design.md`](design.md) → [`install-flow.md`](install-flow.md) + [`patch-programs.md`](patch-programs.md) → [`game-detection.md`](game-detection.md) → [`RELEASING.md`](RELEASING.md) → [`v0.2.0-todo.md`](v0.2.0-todo.md) (açık işler).

**Derleme (Windows, Qt 6.11.1 MinGW, vcpkg klasik mod):**

```bash
python scripts/generate_key_header.py   # bir kez: scripts/.encryption_key → encryption_key.h (ikisi de gitignore'da)
just dev            # Core + UI + testler
just test           # bütün takımlar (32)
just release-zip-dynamic 0.2.2-beta   # yayın ZIP'i; önce testler, sonra Sentry'ye sembol yükler
```

Commit'ler Conventional Commits (`feat(ui): …`), yerel `commit-msg` / `pre-commit` / `pre-push`
kancaları denetler; `pre-push` dev derlemesini ve testleri çalıştırır. CI her `dev` push'unda
Windows'ta derleyip test eder (`.github/workflows/ci.yml`).

**Dallar:** `dev` geliştirme ve yayın etiketleri; `main` ayrı geçmişli varsayılan dal (ortak
atası yok). Zamanlanmış iş akışları (`telemetry-watchdog.yml`) `main`'de olmalı.

**Katalog verisi:** tarif düzeltmesi bir **D1** değişikliğidir (R2'deki `assets/packages/*.json`
eski bir aynadır, launcher okumaz). Launcher'lar `index.json`'u yalnız katalog sürümü değişince
yeniden alır: paneldeki her yayın sürümü artırır; panel dışı değişiklikte "Launcher'lara duyur".
Yeni bir adım türü eski launcher'ı bozar → `steprules::kRecipeLevel`'i artır, eski tarifi
`install_methods_compat`'a koy.

## Tuzaklar (kök `CLAUDE.md` tablosuna ek, operasyon tarafı)

- **`git push` Git Credential Manager'da takılabilir** (Launcher ve WEB): `git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push origin dev`.
- **Makine-WEB `main`'e push canlıya çıkar** (CI: test + derleme + deploy). Yerel `npm run deploy` yalnız temiz ağaçta ve `HEAD == origin/main` iken.
- **D1'de `wrangler d1 migrations apply` kullanma**: eski migration'lar elle uygulanmış, toplu uygulama tohum verisini ezer. Tek dosyayı `d1 execute --file` ile çalıştır.
- **`Makine-Launcher-Assets` `main` = R2**: oraya push `assets/`'i R2'ye eşitler; panelden yayınlanan ama Assets'e girmemiş bir kayıt ezilebilir (liste "panel dışında değişti" diye gösterir).
- **Yayın notu sonrası** `gh release edit` sürümü taslağa çevirebiliyor: `gh release view <etiket> --json isDraft` ile denetle.
- **Test için açılan arka plan süreçlerini kapat** (sınama sunucusu, döngü): bir kez saatlerce iki çekirdeği yedi.
- **QML:** `MultiEffect` maskesi bir eşiktir (`design.md` → Tuzaklar); bir layout'un genişliğini kendinden türetme (sayfa donar); `Connections.target`'ı kendi işleyicisinde değiştirme (NATIVE-74 çökmesi).
