Makine Launcher'ın Qt6/QML mimarisine geçtikten sonra paketlenen ilk sürümü. Kapalı test içindi; herkese açık dağıtımı yapılmadı.

## Bu sürümde ne vardı

- **Oyun tarama** — Steam, Epic Games ve GOG kurulumlarının yerel taranması, katalogla eşleştirme
- **DPI duyarlı arayüz** — Kompakt / Otomatik / Büyük ölçek seçenekleri, küçük ekran uyarlaması
- **Yedekleme koruması** — Oyun başka diske taşındığında özgün yedeklerin korunması, geri yükleme öncesi hedef dizin doğrulaması
- **Ekip güncelleme kanalı** — GitHub üzerinden dağıtım (yalnızca geliştirme yapıları)
- **Duyuru kartı** — Discord bağlantısı

## İndirme

Bu sürümün kurulum paketi arşivde tutulmuyor. Aşağıdaki **Source code** bağlantıları yalnızca etiketin kaynak kodudur; programı kurmak için güncel sürümü kullanın.
