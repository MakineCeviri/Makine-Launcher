## Mimari, kısaca
- **Launcher**: Live `plugins/org.makineceviri.live/` içinde gelir (MSIX'te salt okunur), doğrulanmış, açık; süreç ilk kullanımda başlar
  (`pluginwake.h`), açılışta hiçbir şey çalışmaz. Uzaktan kapatma: CDN `assets/launcher.json` → `plugins.<id>.enabled`.
  GTA VI görseli: `"live": {"gta6Art": false}` ile kapanır. Altyazı penceresi yakalamadan gizli (`capturehide.h`); konsol modunda ve
  "Yayında göster"de görünür.
- **Eklenti**: kendi ONNX Runtime OCR hattı (`src/ocr_ort.*`, ch PP-OCRv3 det+rec, RapidOcrOnnx yok; Microsoft imzalı onnxruntime.dll +
  VC++ dosyaları eklenti klasöründe). Maske ile değişmeyen karede OCR atlanır; altyazı bandı kendiliğinden bulunur
  (`subtitle_finder.*`); uzun çeviri sığdırılır/parçalanır (`fit.*`); konuşmacı adı ayrılır; kesik satır gönderilmez.
  Hata kodları `ui.state.reason` (17 kod). Kısayollar F8/F9/F10 (RegisterHotKey, kanca yok). TV: kendi ADB istemcisi (Android/Fire TV), LG elle.
- **Sunucu**: Live API ayrı Worker `makine-live` (rota `makineceviri.org/api/live/*`; geri alma `Makine-WEB/docs/live-worker.md`).
  Havuz: konuşmacı etiketi anahtarda yok, kesik/birleşik okumalar karantinada, güvenli benzerlik (`sameLine`), "geçici" çeviri.
  Çeviri hafızası: anahtar bağlamsız; kısa satırda bağlam yalnız DeepL ipucu ve yalnız isteyene; sen/siz kuralları (`relations`),
  oyun başına DeepL sözlüğü. DeepL modeli `quality_optimized` (portaldan geri alınır). Sentry: Live hataları/günlük/hız launcher'ın Sentry'sinden
  gider; portal kartı salt okunur token bekliyor (`Makine-WEB/docs/live-sentry.md`).
